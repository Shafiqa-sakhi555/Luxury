# Lexury — Gilgit Baltistan

Premium carpets, sofa sets, curtains, and home furnishings for Gilgit Baltistan, Pakistan.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Color palette

| Token | Color | Use |
|-------|-------|-----|
| Midnight | `#0C1929` | Background |
| Royal Crimson | `#BE123C` | Carpet accent |
| Hunza Turquoise | `#0891B2` | Mountain water |
| Saffron Gold | `#F59E0B` | Warm highlights |
| Wool Cream | `#FDF8F0` | Text |
