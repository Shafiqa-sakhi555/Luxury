# Jalal AI Knowledge Base

Structured, versioned knowledge for **Jalal Assistance**. This is **not** LLM training data — it feeds **RAG indexing** and **tool orchestration**.

## Architecture

```
                 JALAL ASSISTANCE
                        │
              ┌─────────┴─────────┐
              │                   │
        KNOWLEDGE/RAG         LIVE SYSTEMS
        (this folder)         (Supabase + tools)
              │                   │
        Company                  Products (search)
        FAQs                     Prices (live query)
        Policies                 Stock (live query)
        Design rules             Orders (auth)
        Product descriptions     Branches (branches.json + stores)
        Support procedures       Cart / coupons (when built)
              │                   │
              └─────────┬─────────┘
                        │
                   Ollama (local LLM)
```

## What belongs here (static RAG)

| Domain | Path | Source |
|--------|------|--------|
| Company | `company/` | `src/lib/content.ts`, About page |
| Branches | `branches/` | `src/lib/branches.ts` |
| Policies | `policies/` | `src/lib/infoPages.ts` |
| FAQ | `faq/` | `src/lib/infoPages.ts` |
| Design consultation | `design/` | Rules scoped to **live catalog** |
| Product categories | `products/categories/` | Supabase categories (not marketing nav) |
| Product records | `products/export/` | Generated by `npm run assistant:export-products` |
| Support | `support/` | Derived from policies |
| Glossary | `glossary/` | Client-confirmed terms |
| Orders (status meanings) | `orders/` | Static definitions only |
| Visualization | `visualization/` | Planned feature — marked clearly |

## What must NEVER be stored here permanently

- Current prices (use `getProduct` tool)
- Current stock / branch availability (use `checkProductStock` tool)
- Customer PII, passwords, payment details
- Order status for a specific customer (use order tools)
- Unverified product claims

Files marked `"verified": false` or `"placeholder": true` must not be used for factual answers until client approves.

## Live catalog categories (Supabase)

Only these categories exist in the production database today:

- `curtains`
- `prayer-mats`
- `carpets`

Marketing nav items (furniture, flooring, rugs, decor) on the homepage are **not** in the live catalog until added to Supabase.

## Maintenance

1. Edit static content in this folder (or sync from `infoPages.ts` / `branches.ts`).
2. Run `npm run assistant:export-products` after catalog changes (descriptions/specs only).
3. Run `npm run assistant:reindex` (Phase 2) to refresh pgvector embeddings.

## Index metadata schema

Each chunk indexed into pgvector should carry:

```json
{
  "sourceType": "company|faq|policy|product|category|design|support|glossary",
  "sourceId": "path-or-id",
  "productId": "optional-uuid",
  "categoryId": "optional-uuid",
  "contentType": "overview|faq|policy|description|rule",
  "language": "en",
  "verified": true,
  "updatedAt": "ISO-8601"
}
```
